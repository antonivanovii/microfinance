# Дизайн-система

Перенос `01 Дизайн-система.dc.html` из `Макеты для МФО приложения 2/`.
Макет — источник истины: недостающий токен или состояние заводится в макете,
а не хардкодится здесь.

```
tokens/   цвет, типографика, форма, движение
styles/   @font-face, reset, база
assets/   маскот и 3D-объекты
ui/       компоненты
a11y/     фокус-трап, dismiss, замок прокрутки, media query
lib/      деньги, даты, склонения
```

Импорт — `@ds/ui`, `@ds/lib`, `@ds/assets`, `@ds/a11y`.

## Что стоит знать до правок

Компонент берёт семантический токен (`--color-accent`), не примитив
(`--brand-500`). Хардкод цвета, кегля, отступа или радиуса в `*.module.css` —
повод для правки на ревью.

Готовых headless-библиотек нет, поведение примитивов написано руками —
поэтому фокус, клавиатура и роли покрыты тестами рядом с компонентами.

Суммы приходят с сервера посчитанными и отформатированными. Компоненты их не
считают: `AmountSlider` поэтому работает в шагах, а не в рублях.

Шрифты локальные, по копии в `public/fonts/` каждого приложения. Меняешь
набор начертаний — правишь `styles/fonts.css` и обе папки.
